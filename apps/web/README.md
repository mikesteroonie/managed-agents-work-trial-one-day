# Web application

The AgentMail team will add a runnable Next.js and TypeScript console shell with a Managed Agents sidebar destination and an assumed logged-in workspace. AgentMail API credentials are supplied separately.

You build the agent builder, application APIs, and integration with AgentMail's existing API and webhook service, including event parsing/validation and local replay tooling. The surrounding console and authentication are supplied context; AgentMail is the only connector.
