# Console application

The AgentMail team will add a runnable Next.js/TypeScript console shell with a Managed Agents sidebar destination and an assumed logged-in workspace. A configured server-side AgentMail SDK client and trial credentials are supplied; see the [integration guide](../../docs/AGENTMAIL.md).

Build the screens, application APIs, schema, and execution integration described in the repository README. You own webhook registration, intake/validation, routing, and local replay tooling. AgentMail is the only connector.
